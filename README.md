# SO X Server

## التشغيل محليًا
1. `npm install`
2. انسخ `.env.example` إلى `.env` وعدّل القيم (خصوصًا JWT_SECRET واسمك الحقيقي).
3. `export $(cat .env | xargs) && npm start`
4. ضع صفحة الموقع في مجلد `public/index.html`.

## النشر على Railway
- ارفع المجلد على GitHub وأنشئ مشروعًا في Railway.
- أضف متغيرات البيئة من `.env.example` في إعدادات المشروع.
- أضف Volume وثبّته على مسار `sox.db` حتى لا تضيع البيانات.

## طريقة الدفع بفودافون كاش
**الوضع اليدوي (يعمل فورًا):** الرقم 01015224774 واسمك يظهران للعميل بوضوح مع كود طلب فريد. العميل يحوّل، ثم يرسل رقمه عبر `/api/orders/:ref/paid`. يصلك إشعار تيليجرام، وتؤكد الطلب من `/api/admin/orders/:ref/confirm` بعد رؤية رسالة فودافون كاش على موبايلك. بعد التأكيد يُفعَّل الاشتراك أو يُحجز الكارت.

**الوضع التلقائي (موصى به للنمو):** المحفظة الشخصية لا توفر ربطًا برمجيًا، لذلك افتح حساب تاجر على Paymob وفعّل تكامل محفظة الموبايل. أضف المفاتيح في `.env` واجعل رابط الـ webhook: `https://موقعك/api/paymob/webhook`. التأكيد وقتها يتم تلقائيًا مع فحص توقيع HMAC. راجع وثائق Paymob الحالية قبل الإطلاق لأن حقول التوقيع قد تتغير.

## التأكيد التلقائي لفودافون كاش (بدون تدخل منك)
المحفظة الشخصية لا تعطي واجهة برمجية، فالحل أن هاتفك الذي عليه المحفظة يمرّر رسائل «استلام أموال» للخادم:
1. ثبّت على هاتف المحفظة (أندرويد) تطبيق تمرير رسائل مثل «SMS Forwarder» أو «HTTP SMS».
2. اجعله يرسل كل رسالة واردة من فودافون كاش بطلب POST إلى `https://موقعك/api/sms-webhook` بصيغة JSON: `{"text":"نص الرسالة"}` ومعه الهيدر `x-sms-secret` بنفس قيمة `SMS_WEBHOOK_SECRET`.
3. الخادم يقرأ المبلغ ورقم المحوِّل ويطابقهما مع الطلب (نفس المبلغ ونفس رقم الهاتف الذي أدخله العميل)، ثم يفعّل الاشتراك أو يحجز الكارت ويرسل لك إشعارًا.
4. اختبر بتحويل 10 جنيه من رقم آخر. لو صيغة رسالة فودافون عندك مختلفة ولم تُفهم، يصلك إشعار بنصها لتؤكد يدويًا من لوحة الإدارة، ويمكن تعديل نمط القراءة في `/api/sms-webhook`.
- الطلبات غير المدفوعة تنتهي تلقائيًا بعد 24 ساعة.
- للتأكيد التلقائي عبر بوابة رسمية بدل الرسائل استخدم Paymob (الويب هوك جاهز).

## الباقات والعمولة والدعوات
- الشهر الأول 10 جنيه (للمشتركين الجدد فقط)، شهري 30، 3 شهور 75، سنوي 240
- عمولة 4% على كل كارت يتباع، وأول بيعة لكل بائع بدون عمولة
- كود دعوة لكل مستخدم (`/api/me`)، ويُرسَل عند التسجيل في حقل `invite`. عند أول دفع للمدعو يحصل صاحب الكود على أسبوع مجاني
- `/api/plans` لعرض الباقات، و`/api/stats` لأرقام حقيقية فقط (كروت منشورة ومباعة ومشتركون)

## ما يتضمنه الخادم
- تسجيل ودخول بكلمات مرور مشفرة وكوكي آمن وحد لمحاولات الدخول
- اشتراك 10 جنيه لمدة 30 يومًا، ولا ينشر كارتًا إلا المشترك
- إشعارات لك بكل طلب وتحويل وتأكيد وبلاغ مع التاريخ والوقت
- بلاغات: 3 بلاغات تخفي الكارت للمراجعة، وحظر الحساب يحذف كروته
- سجل عمليات (audit) لكل إجراء إداري

## قبل الإطلاق
- راجع الشروط والخصوصية مع مختص قانوني، وسجّل النشاط حسب القانون المصري.
- أضف حدًا لعدد الكروت لكل مستخدم وفحصًا لحجم الصور.
- فعّل نسخًا احتياطيًا لقاعدة البيانات.
